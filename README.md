# 🏷️ Hashtag For Services - نظام إدارة الخدمات

منصة احترافية لإدارة خدماتك وتوزيع الطلبات على موظفيك عبر WhatsApp بسهولة!

## ✨ المميزات

- 📱 ربط مباشر مع WhatsApp
- 👥 إدارة بيانات الموظفين والخدمات
- 🎯 توزيع ذكي للطلبات
- 🎨 واجهة احترافية وسهلة الاستخدام
- 🔔 رسائل ترحيب مخصصة
- 📋 خدمات مشتركة بين الموظفين

## 🚀 البدء السريع

```bash
cd hashtag-for-services
npm install
npm start
```
